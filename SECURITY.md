# Security Policy

## Supported Versions

Security support starts with the default branch and the latest tagged release once releases begin.

## Reporting a Vulnerability

Please do not open public issues for sensitive vulnerabilities.

Until a dedicated security contact is published, report vulnerabilities privately to the repository owners through GitHub security reporting or a private maintainer channel.

## Response Goals

- acknowledge reports promptly
- assess impact and reproducibility
- coordinate a fix and disclosure plan
